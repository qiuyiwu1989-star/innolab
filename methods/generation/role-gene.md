# 角色基因理论（Role Gene Model）

## 元信息
- ID: GN02
- Engine: Generation
- Layer: L4
- Origin: original
- 来源：造物云IP设计体系，邱懿武

一句话定义：为IP角色定义完整"基因卡"——外在特征×内在人格×行为模式×叙事弧线，四个维度确保角色一致性和生命力。不是"画一个好看的形象"，是"创造一个活的人"。

---

## 解决什么问题

没有这个方法时，IP角色设计常见问题：
- **形象空洞**：画得很好看但说不出"他是谁"——无法做内容延展
- **人格不一致**：换个场景角色行为就变了——A作者和B作者写出来的不像同一个人
- **没有成长性**：角色永远是固定的——无法做长期内容和叙事

基因理论的核心主张：**角色的"基因"决定了他在任何场景下会做什么**——定义清楚基因，角色就有了自主性。

## 核心框架：四维基因卡

```
┌─────────────────────────────────┐
│ 第四维：叙事弧线                 │
│ 角色如何成长、变化、遇到挑战      │
├─────────────────────────────────┤
│ 第三维：行为模式                 │
│ 习惯动作/口头禅/社交风格/决策方式 │
├─────────────────────────────────┤
│ 第二维：内在人格                 │
│ MBTI/核心动机/恐惧/价值观        │
├─────────────────────────────────┤
│ 第一维：外在特征                 │
│ 外貌/色彩/标志元素/表情体系       │
└─────────────────────────────────┘
```

**维度之间的逻辑**：外在是第一印象，人格是行为的驱动力，行为是人格的外显，叙事是行为积累的结果。

## 怎么用

### 第一维：外在特征
- **基本设定**：年龄/性别/种族/体型
- **视觉标志**：3个让人一眼记住的视觉元素（如：红头发+大眼镜+永远背着的包）
- **色彩体系**：主色/辅色，以及为什么选这个颜色
- **表情体系**：6-12个标准表情（开心/难过/惊讶/思考/生气/调皮…）

### 第二维：内在人格
- **MBTI类型**：不是随便选，要跟行为模式一致
- **核心动机**：他最想要什么？（归属感/成就/自由/安全…）
- **核心恐惧**：他最怕什么？（被抛弃/失败/无聊/失控…）
- **价值观**：他相信什么？（努力一定有回报/朋友比钱重要/活在当下…）

### 第三维：行为模式
- **口头禅**：2-3句反复说的话（要跟人格一致）
- **习惯动作**：思考时会做什么、紧张时会做什么
- **社交风格**：主动还是被动？话多话少？对陌生人vs对朋友？
- **决策方式**：冲动还是谨慎？听直觉还是分析数据？

### 第四维：叙事弧线
- **起点**：角色出场时是什么状态
- **转折**：会遇到什么挑战，如何应对
- **成长**：经过挑战后有什么变化
- **开放性**：留出未来发展的可能性

### FiFi格式输出（造物云标准模板）

完整基因卡包含：标题、基本信息、灵感来源、生日、角色传记、梦想、特殊技能、饮食偏好、外观描述、色彩与材质、性格特征、MBTI、定位与目标受众、品牌应用（产品线/营销场景/衍生内容）。

## 诊断分级

| 等级 | 特征 |
|------|------|
| S级 | 四维齐全，人格驱动行为（逻辑一致），叙事弧线有完整故事，可以交给任何创作者产出一致内容 |
| A级 | 前三维到位，叙事弧线有方向但缺细节 |
| B级 | 只有外在特征+简单人格，行为模式不清晰 |
| C级 | 只有外观——"画了一个好看的角色" |

## 案例

**场景**：球球老师的基因卡设计

| 维度 | 内容 |
|------|------|
| 外在 | 无实体形象（AI对话产品），但有"声音人格"——温暖、好奇、不装 |
| 内在人格 | INFP（理想主义者），核心动机是"让每个孩子的内心世界被看见"，恐惧是"伤害孩子" |
| 行为模式 | 口头禅"真的吗？展开说说"，不连续提问（兜兜教训），被纠正后180度转向是错误行为 |
| 叙事弧线 | 从"教知识的AI"→发现"灵魂对话"才是核心→不断被孩子教怎么做更好的对话 |

## 常见陷阱

1. **外在压倒内在**：花大量时间画形象但人格是空的。**纠偏**：先定义内在人格和行为模式，再设计外在——外在应该反映内在。
2. **人格跟行为矛盾**：说角色是"内向害羞"但行为上"主动社交"。**纠偏**：用"在XX情境下会XX"的方式验证每个行为是否跟人格一致。
3. **没有叙事弧线**：角色永远不变。**纠偏**：即使是产品化的IP也需要成长——用户会"养成"角色。
