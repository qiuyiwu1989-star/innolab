# 头脑风暴（Brainstorming）

## Meta
- ID: GN08
- Engine: Generation
- Layer: L2
- Origin: classic

---

## Definition
头脑风暴是一种经典的创意激发方法，通过小组内成员互相激发想法，在短时间内产出大量创意。核心遵循四原则：不评判、追求数量、鼓励狂想、组合改进。

## Core Idea
创意的敌人是评判。头脑风暴的精髓在于将"产生想法"和"筛选想法"严格分开——在产生阶段，任何想法都值得说出口，哪怕听起来荒谬。因为一个疯狂的想法可能激发另一个可行的想法。数量先于质量。

## Use Cases
- 产品创新初期的发散探索
- 解决具体问题时寻找多种可能方案
- 团队建设中的创意协作
- 项目启动前的机会扫描
- 突破现有方案的局限性

## Input
- 明确的创意挑战问题（一句话说清楚要解决什么）
- 参与者（4-8人为佳，跨职能更优）
- 时间框（通常15-45分钟）
- 可选：约束条件（预算、时间、技术限制）

## Output
- 大量创意点子（目标：30分钟产出50+个）
- 初步分类的创意群组
- Top 10值得进一步探索的创意

## Steps
1. **定义挑战**：用一句话明确创意挑战。格式："我们如何能够____？"（How Might We...）
2. **宣读四原则**：
   - 不评判：产生阶段禁止批评、质疑、说"但是"
   - 追求数量：目标是尽可能多的想法，越多越好
   - 鼓励狂想：越大胆越好，"不可能"的想法往往最有价值
   - 组合改进：可以在别人的想法上叠加、改进、变体
3. **快速发散**：每人轮流说想法，每轮每人说一个，记录在白板/便签上。保持节奏，每个想法不超过30秒
4. **追加轮次**：发散结束后，鼓励"疯狂变体"——对已有想法做极端变化（放大10倍？缩小10倍？反过来？）
5. **沉默追加**：给3分钟安静时间，每人默默写下之前没说出口的想法
6. **分类整理**：将所有创意分为3-5个主题组
7. **投票筛选**：每人3票，投给最想深入探索的创意。选出Top 10

## Cases
1. **IDEO购物车重设计**：IDEO团队对"如何重新设计购物车"进行头脑风暴，4天产出数百个创意。关键狂想："如果购物车能自动驾驶跟人走？""如果购物车能帮人找商品？"这些看似疯狂的想法最终催生了购物车嵌入扫描器、GPS导航等实用创新。
2. **3M便利贴的诞生**：3M科学家Spencer Silver在研究强力胶水时"失败"了——做出了一种粘性很弱的胶水。同事Art Fry在教堂唱诗时脑暴"如果这种弱粘性用在书签上"——便利贴由此诞生。组合改进+狂想=革命性产品。

## Limitations
- "群体思维"风险：强势参与者可能主导方向，内向者想法被压制
- "社会惰化"：部分参与者可能搭便车
- 产出质量参差不齐，大量创意需要后续筛选和验证
- 不适合需要深度思考的技术问题
- 线上远程效果通常不如线下

## Method Relations
- **前置方法**：What If（GN07）——用What If打开思维后再做头脑风暴；设计思维（design-thinking）——头脑风暴是设计思维"发散"阶段的核心方法
- **后续方法**：亲和图（CG18）——对头脑风暴产出进行分类整理；概念提炼（GN10）——将创意转化为可执行的概念
- **互补方法**：六顶思考帽（CG09）——头脑风暴产出发散，六顶思考帽做收敛评估
- **对比方法**：与行为风暴（GN09）对比——头脑风暴是语言发散，行为风暴是身体行动激发

## Prompt
你是一位创意激发教练。请围绕以下挑战组织一次头脑风暴：

**创意挑战**：[用户填写]
**背景信息**：[用户填写]
**约束条件**：[用户填写，可选]

请模拟执行以下步骤：
1. 将挑战转化为"How Might We..."问题
2. 按四原则产出至少30个创意（覆盖不同方向：渐进式/颠覆式/跨界式/极端式）
3. 追加5个"疯狂变体"（极端版本）
4. 将所有创意分为3-5个类别
5. 选出Top 10最有潜力的创意，简述理由

要求：
- 创意要多样化，不要集中在同一方向
- 狂想要真的狂（让人第一反应是"不可能"但细想有道理）
- 每个创意用一句话表述，简洁有力

输出格式请严格按照Output Format要求。
