# 假如…会怎么样（What If）

## Meta
- ID: GN07
- Engine: Generation
- Layer: L3
- Origin: classic

---

## Definition
"假如…会怎么样"是一种反向提问法，通过刻意挑战行业的基本假设、常识和"理所当然"，提出颠覆性的What If问题，打破惯性思维，探索全新可能性。

## Core Idea
每一个行业都有一套没人质疑的基本假设——"酒店必须有房间"、"出租车必须有车"、"银行必须有网点"。What If方法的核心是把这些假设逐个翻转，看看翻转之后会发生什么。颠覆式创新往往不是"做得更好"，而是"问了一个不同的问题"。

## Use Cases
- 创新瓶颈期需要突破性思路
- 行业同质化严重时寻找颠覆方向
- 新进入者寻找不对称竞争切入点
- 战略规划中探索"极端情景"
- 创业方向探索和头脑风暴热身

## Input
- 行业或品类名称
- 行业的基本假设清单（"我们行业一直这样做"）
- 可选：现有痛点或限制条件

## Output
- 翻转假设清单（至少10个What If问题）
- 每个What If的可行性初判
- Top 3最有潜力的颠覆方向

## Steps
1. **列出基本假设**：写下你所在行业的10个"理所当然"的规则或假设
2. **逐条翻转**：对每个假设问"What If反过来会怎样？"
3. **展开想象**：对翻转后的情景进行5分钟自由联想——会发生什么？谁会受益？谁会受损？
4. **可行性初筛**：快速判断每个What If的可行性（技术上可实现？法规允许？用户接受？）
5. **深度展开**：对Top 3最有潜力的What If进行详细推演
6. **转化为机会**：将推演结果转化为具体的创新方向或产品概念

## Output Format
```
# What If 分析 · [行业/品类]

## 行业基本假设
| # | 假设 | "理所当然"的原因 |
|---|------|-----------------|
| 1 | [假设1] | [为什么大家这样做] |
| 2 | [假设2] | ... |

## What If 翻转
| # | 假设 | What If反过来... | 可能性 | 冲击力 |
|---|------|-----------------|--------|--------|
| 1 | [假设] | [翻转后的情景] | 高/中/低 | ⭐⭐⭐⭐⭐ |

## Top 3 颠覆方向

### 1. [方向名]
- **What If**：[问题]
- **推演**：[如果真的这样，会发生什么]
- **现实案例**：[是否有已验证的案例]
- **行动建议**：[我们能做什么]

### 2-3. ...
```

## Cases
1. **Airbnb的What If**：酒店业的基本假设是"旅行住宿需要专业房间"。What If反过来："假如任何人都可以出租自己的家呢？"——这个看似荒谬的问题催生了估值超过希尔顿的Airbnb。
2. **Spotify的What If**：音乐行业的假设是"用户要拥有音乐"。What If反过来："假如用户不需要拥有音乐，只需要随时能听到呢？"——从所有权到使用权的翻转创造了流媒体时代。

## Limitations
- What If容易产出"听起来酷但不可能实现"的想法，需要可行性筛选
- 对高度监管的行业（医疗、金融），很多翻转受法规限制
- 团队可能陷入"为反而反"的陷阱，产出与实际需求脱节
- 需要后续方法（如原型法、评估矩阵）将想法落地

## Method Relations
- **前置方法**：十环分析法（PD11）——用十环找到创新盲区，再用What If在盲区上做颠覆
- **后续方法**：概念提炼（GN10）——What If产出的颠覆想法需要概念化；原型法（GN11）——将概念做成可测试的原型
- **互补方法**：蓝海战略（blue-ocean）——What If找到翻转方向，蓝海战略做系统性价值创新
- **对比方法**：与头脑风暴对比——头脑风暴是自由发散，What If是结构化反向（针对特定假设翻转）

## Prompt
你是一位颠覆式创新导师。请对以下行业执行What If分析：

**行业/品类**：[用户填写]
**领域背景**：[用户填写]

请按以下步骤执行：
1. 列出该行业10个"理所当然"的基本假设（越基础越好）
2. 对每个假设提出What If翻转问题
3. 对每个What If快速评估可能性和冲击力（1-5分）
4. 选出Top 3最有潜力的What If进行深度推演
5. 对每个Top 3给出：推演情景、是否有现实验证案例、具体行动建议

要求：假设要触及行业根基（不要表面假设），翻转要大胆但有逻辑推演支撑。

输出格式请严格按照Output Format要求。
