# 颠覆性思维的产品路演法（Disruptive Roadshow Narrative）

## Meta
- ID: GN06
- Engine: Generation
- Layer: L4
- Origin: original
- Source: 邱懿武原创，基于颠覆性创新理论的路演叙事框架
- First Published: InnoLab v3

## Definition（一句话定义）

将模糊的产品/创意想法，通过9页认知反转结构，生成一套从现状反思到方案承接的路演叙事逻辑。

## Core Idea（核心思想）

路演的本质不是推销产品，而是**重构听众的认知框架**。大多数路演失败不是因为产品不好，而是听众带着旧的认知框架来听，自然觉得"没必要"。这个方法的核心是：先拆掉旧框架，再植入新框架，产品只是新框架的自然结论。

逻辑链：**现状 → 代价 → 共鸣 → 认知反转 → 新机会 → 类比降低理解成本 → 方案承接 → 行动理由 → 未来愿景**

## Use Cases（适用场景）

- 产品路演 / 路演PPT结构梳理
- 创业融资 pitch deck 的叙事逻辑检查
- 内部提案的认知框架设计
- 将模糊想法转化为有说服力的叙事
- 检查已有路演稿的逻辑断层

## Input（输入）

以下任一：
- 一个模糊的想法或创意
- 一个产品或项目的简单描述
- 一段路演/PPT的草稿文字
- 一个正在思考但还不清晰的方向

## Output（输出）

按9页结构输出每页的【分析要点】+【建议要点】，最后给出整体叙事评价。

## Steps（使用步骤）

### 第1页｜描述现状
分析当前领域中"大家习以为常的做法"，存在的默认规则，目前主要追求的目标。

### 第2页｜观察结果
现有做法在现实中产生的实际结果，哪些结果与最初目标出现偏差，是否存在被忽略的长期代价。

### 第3页｜讲一个故事
用"具体人+场景+情绪"承载前面的问题，让听众产生共鸣。给叙事方向，不编造完整故事。

### 第4页｜颠覆性的结论（认知反转）
完成一次清晰的认知反转："我们一直以为问题在【A】，但真正的问题其实在【B】。"

### 第5页｜颠覆性的机会
新问题定义下机会出现在哪里，哪些原本被忽略的地方变得重要，竞争方式是否改变。

### 第6页｜进行类比
用已发生过的变化帮助理解，降低认知成本。

### 第7页｜介绍方案
方案在整个逻辑中的位置，解决的是哪个关键节点问题，是否与认知反转形成自然承接。

### 第8页｜鼓励改变
直接变化是什么，哪些成本/风险/不确定性被降低，是否足以推动行动意愿。

### 第9页｜展望未来
长期方向是什么，未来新常态是什么，是否与最初"现状"形成首尾呼应。

## Example（示例）

输入：「我们想做一个AI辅助教师备课的工具」

输出概要：
- 第1页：教师每天花2-3小时手动备课，重复制作课件、搜索素材
- 第2页：大量时间花在"搬运"而非"设计"，教学质量被挤压
- 第3页：张老师，教了8年语文，每天晚上10点还在找素材，周末也备不完
- 第4页：我们一直以为问题在"教师不够努力"，但真正的问题在"备课流程本身是重复劳动"
- 第5页：如果重复劳动能被接管，教师的创造力空间被释放
- 第6页：类比：会计从手工记账到Excel——不是会计变懒了，是工具升级了
- 第7页：我们的工具定位在"素材生成+教案结构化"这个节点
- 第8页：教师每天省出1.5小时，用于课堂互动和学生辅导
- 第9页：未来教师的核心价值是"教学设计"而非"资料搬运"

## Pitfalls（注意事项/常见误区）

- 不是营销文案工具，核心是认知路径的结构化
- 第4页的认知反转是整套结构的灵魂，不能跳过或敷衍
- 第3页的"人的视角"不是煽情，而是让问题落地
- 方案（第7页）不能出现太早，否则听众会带着防御心态听后面的分析
- 避免空口号，每个判断都要有事实或逻辑支撑

## Deep Understanding（深度理解）

- 与 C08 推导式写作法的区别：推导写作偏文章（线性论证），路演法偏PPT演示（节奏感+视觉化+认知反转）
- 与 C11 金字塔原理的区别：金字塔偏"我怎么表达清楚"，路演法偏"听众怎么被说服"
- 与 GN05 设计思维的区别：设计思维偏"怎么做出对的产品"，路演法偏"怎么讲清楚为什么需要这个产品"
- 高阶用法：可用此方法反过来检查产品定义——如果9页结构讲不通，说明产品定位本身有问题
