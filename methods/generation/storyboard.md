# 故事板（Storyboard）

## Meta
- ID: GN12
- Engine: Generation
- Layer: L3
- Origin: classic

---

## Definition

故事板是一种用视觉叙事方式展示产品在具体使用场景中如何被使用的方法，通过连贯的画面序列激发同理心，让团队和利益相关者"看见"用户体验。

## Core Idea

"先让所有人看到同一个故事，再讨论要不要改这个故事。"故事板的价值不是画得好，而是**让隐性假设变成显性画面**。

## Use Cases

- 向非技术背景的利益相关者传达产品概念
- 让团队对齐用户使用场景
- 发现服务流程中的断裂点
- 激发团队对用户的同理心
- 商业路演中展示产品体验

## Input

- 用户画像（who）
- 使用场景（where, when）
- 用户目标（what they want）
- 产品如何介入（how）

## Output

- 6-12格故事板（含画面+文字说明）
- 用户情绪曲线标注
- 产品介入的关键时刻

## Steps

1. **确定主角**：基于用户画像，给主角一个名字和背景
2. **设定场景**：主角在什么时间、什么地点、遇到了什么问题
3. **构建故事弧**：
   - 开场：现状/问题出现
   - 转折：产品介入
   - 高潮：核心体验
   - 结局：问题解决/状态改变
4. **画出每个场景**：每格包含画面+简短文字说明
5. **标注情绪**：在每个场景下标注用户情绪（😟→😐→😊）
6. **检查完整性**：故事是否连贯？有没有跳步？

## Output Format

```
故事标题：[场景名称]
主角：[姓名]，[身份]，[核心痛点]
场景：[时间] + [地点]

第1格：[画面描述]
  文字：[场景说明]
  情绪：😟

第2格：...

...

情绪曲线：😟→😐→🤔→😊
关键发现：[通过讲故事发现的意外洞察]
```

## Cases

**案例1：在线教育App**
主角小李，28岁上班族，想利用通勤时间学英语。故事板展示了他从"地铁上掏出手机→打开App→找不到合适的课程→放弃→第二天换了另一个App"的完整流程。通过故事板发现：**用户第一次打开App的30秒体验是关键断裂点**。

**案例2：社区团购**
主角王阿姨，55岁，不太会用手机但想省钱买菜。故事板展示了她从"邻居推荐→下载App→不知道怎么拼团→叫孙子帮忙→终于下单→收到菜发现比超市便宜"的过程。发现：**核心障碍不是"不会用"，而是"没有人带第一步"**。

## Limitations

- 画技好坏影响表达效果（可借助模板或工具）
- 过于简化的场景可能遗漏关键细节
- 故事板是线性的，难以展示分支选择
- 需要对用户有足够了解才能编出真实故事

## Method Relations

- 前置：人物原型（user-persona）提供主角画像
- 前置：使用者旅程图（customer-journey）提供流程骨架
- 后续：原型法（GN11）将故事板转化为可交互原型
- 配合：设计民族志（CG17）提供真实用户洞察作为故事素材
- 配合：行为风暴（GN09）可以用"演"的方式测试故事板

## Prompt

你是一位视觉叙事专家。用户会给你一个产品概念或用户场景，请帮他们：

1. 设计一个有真实感的主角（姓名、年龄、职业、痛点）
2. 构建完整的6-12格故事板（每格含画面描述+文字说明）
3. 标注每格的用户情绪变化
4. 找出故事中"产品介入"的关键时刻
5. 指出通过这个故事发现的潜在问题或机会

故事要真实、具体、有细节——避免"用户很开心地使用了产品"这种空洞结局。
