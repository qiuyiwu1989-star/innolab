# 亲和图（Affinity Diagram）

## Meta
- ID: CG18
- Engine: Cognition
- Layer: L3
- Origin: classic

---

## Definition
亲和图是一种将大量零散观察结果、想法或数据通过"沉默分组法"进行自下而上分类整理的工具。团队成员在不讨论的情况下独立将相似的卡片归为一组，再集体为每组命名，从而从杂乱信息中自然浮现出模式和结构。

## Core Idea
当信息量大到让人无从下手时，不要试图先建立框架再去分类——让模式自己浮现。亲和图的"沉默分组"设计刻意阻断讨论，避免权威效应和锚定偏见，让最自然的分组方式自动出现。

## Use Cases
- 用户研究后整理大量观察笔记和访谈记录
- 头脑风暴后筛选和组织创意
- 团队对复杂问题建立共同理解
- 问题根因分析中的信息整理
- 需求梳理和优先级排序的前置步骤

## Input
- 需要整理的原始信息（观察记录、访谈笔记、创意列表、问题清单等）
- 每条信息写在一张独立卡片（实体便签或数字卡片）
- 建议数量：50-200张卡片效果最佳

## Output
- 分好组的卡片集合（通常产生5-10个大组，每组3-15张）
- 每组的命名标签（一句话概括该组的核心主题）
- 组间关系图（可选：哪些组之间有强关联）

## Steps
1. **制卡**：将所有观察结果、想法、数据逐条写在独立卡片上，每张卡片只写一条，用简短的陈述句
2. **沉默分组**：将所有卡片铺在桌面。所有人同时、沉默地移动卡片，把感觉相关的卡片放到一起。不允许说话、不允许争论——只凭直觉移动
3. **二次沉默分组**：对已经形成的小堆卡片进行二次审视，可以拆散不合适的组合，也可以合并相邻的小堆。仍然沉默
4. **集体命名**：分组稳定后，团队讨论并为每组起一个名称。名称应概括该组的核心主题，用名词短语而非动词
5. **层级整理**：如果某些组太大（>15张），可拆分为子组；如果某些组太小（<3张），考虑合并
6. **关系标注**：用连线标注组与组之间的关系（因果、矛盾、互补等）
7. **总结洞察**：回顾整个分组结构，提炼3-5条关键发现

## Output Format
```
# 亲和图 · [主题]

## 原始卡片数：[N] 张 → 分为 [M] 组

## 分组结果

### 组1：[组名]

- [卡片内容2]
- ...
（共 X 张卡片）

### 组2：[组名]
- ...

### 组3-M：[组名]
- ...

## 组间关系
- 组1 ↔ 组3：[关系描述]
- 组2 → 组5：[因果/影响关系]

1. **[发现标题]** — [描述]

3. ...
```

## Cases
1. **智能家居用户研究整理**：某智能家居团队完成12户家庭的入户访谈后，将187条观察笔记做成卡片进行亲和图分析。沉默分组自然浮现出7个主题组，其中"临时变通方案"组（用户自己发明的智能家居使用方式）最大，包含34张卡片。这个发现直接催生了"用户自定义场景"功能。
2. **医院急诊流程优化**：一家医院对急诊科200条患者反馈做亲和图分析，沉默分组产生8组。"等待焦虑"组和"信息断层"组之间有强关联——患者焦虑的核心不是等待时间本身，而是不知道还要等多久。解决方案是增加等候区的实时进度显示。

## Limitations
- 卡片数量过少（<30张）时分组意义不大
- 沉默分组对线上远程协作不够友好（需要数字化工具支持）
- 分组结果受参与者背景和经验影响，不同团队可能产生不同分组
- "命名"环节容易滑入讨论陷阱，需要强引导
- 对高度专业化的技术信息不太适用

## Method Relations
- **前置方法**：设计民族志（CG17）——亲和图是整理民族志田野笔记的标准方法；头脑风暴（GN08）——对头脑风暴产出的大量创意进行组织
- **后续方法**：九宫格分析法（CG08）——将亲和图的分组填入九宫格进行结构化分析；评估矩阵（DC07）——对分组后的主题进行优先级评估
- **互补方法**：金字塔原理——亲和图是自下而上归纳，金字塔是自上而下演绎，两者结合效果最佳
- **对比方法**：与预设框架分类对比——亲和图让模式自然浮现，预设框架分类用已知结构套数据

## Prompt
你是一位信息整理专家。请对以下原始信息执行亲和图分析：

**主题**：[用户填写]
**原始信息**：[用户粘贴的观察记录/访谈笔记/创意列表]

请按以下步骤执行：
1. 将原始信息拆分为独立卡片（每条一个卡片，编号）
2. 进行沉默分组：凭直觉将相似卡片归为一组（不需要解释原因）
3. 对分组进行二次调整：拆散不合适组合，合并相近小堆
4. 为每组起一个名称（名词短语，概括核心主题）
5. 标注组与组之间的关系
6. 提炼3-5条关键发现

要求：
- 分组数量控制在5-10组
- 每组至少3张卡片
- 组名简洁有力（3-8个字）
- 关键发现要有"意外感"——不是显而易见的结论

输出格式请严格按照Output Format要求。
