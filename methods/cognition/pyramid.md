# 金字塔原理（Pyramid Principle）

## Meta
- ID: CG12
- Engine: Cognition
- Layer: L2
- Origin: classic
- Source: Barbara Minto, McKinsey
- First Published: 1987年

## Definition（一句话定义）

SCQA结构化表达，将混乱思路转为清晰逻辑——"结论先行，以上统下，归类分组，逻辑递进。"

## Core Idea（核心思想）

表达的本质不是"说清楚自己想说什么"，而是"让对方最快抓住重点"。金字塔原理的底层逻辑是：人的短期记忆容量有限，先给结论再展开理由，认知负担最小。

## Use Cases（适用场景）

- 深度文章结构整理
- 投资人路演PPT逻辑框架
- 产品文档或方案撰写
- 会议汇报思路整理

## Steps（使用步骤）

1. **目标与受众**：给谁看？他们最关心什么？
2. **核心结论**：一句话说清最核心信息（金字塔塔尖）
3. **SCQA引入**：S背景→C冲突→Q疑问→A回答
4. **三层搭建**：核心结论→2-4个论点→每论点2-4条论据
5. **逻辑检验**：上下层一致？同层归类合理？

## 核心框架

**四大原则：**
| 原则 | 含义 |
|------|------|
| 结论先行 | 先说结论，再说理由 |
| 以上统下 | 上层观点涵盖下层论据 |
| 归类分组 | 同层内容属于同一类型 |
| 逻辑递进 | 同层有序排列（时间/重要性/演绎） |

## Pitfalls（注意事项/常见误区）

- 金字塔是"论证关系"不是"时间顺序"，两者容易混淆
- 最常见错误：结论藏在最后——应改为"结论开头+理由展开"
- SCQA的"冲突"是"与现状的反差"，可以是好机会也可以是坏问题

## Deep Understanding（深度理解）

- 与 CG13 推导式写作的区别：金字塔是"自上而下表达"（先结论后理由），推导写作是"自下而上推导"（让读者跟着推导出结论）
- 与 GN06 路演法的区别：金字塔偏"逻辑清晰"，路演法偏"认知反转+说服力"
- 高阶用法：金字塔搭建完成后，可用 GN06 路演法检查"听众的认知框架是否被有效拆解"
