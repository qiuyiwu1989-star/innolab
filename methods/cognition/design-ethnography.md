# 设计民族志（Design Ethnography）

## Meta
- ID: CG17
- Engine: Cognition
- Layer: L4
- Origin: classic

---

## Definition
设计民族志是一种深度用户研究方法，研究者深入用户的真实生活环境，通过观察、沉浸、访谈和记录四种方法，以同理心视角理解用户的行为、动机和未被言说的需求，从而获得传统数据无法揭示的设计洞见。

## Core Idea
用户说的和做的往往不一致。设计民族志的核心信念是：真正的洞见不在问卷里，不在焦点小组里，而在用户真实生活的细节中。只有走进用户的世界，才能看到他们自己都意识不到的需求。

## Use Cases
- 新产品开发前的深度用户洞察
- 现有产品的体验优化（发现用户"将就"的痛点）
- 进入新市场或新人群时的理解
- 团队对用户需求产生分歧时的事实校准
- 服务设计中识别关键时刻（moments of truth）

## Input
- 研究目标（要理解什么用户群体的什么行为）
- 访谈提纲（半结构化，5-10个开放性问题）
- 观察计划（观察场景、时间、注意事项）
- 可选：用户日记模板（让用户自行记录）

## Output
- 田野笔记（观察+沉浸+访谈的原始记录）
- 用户行为模式地图
- 关键洞见清单（至少5条）
- 设计机会点（从洞见到产品/服务方向）

## Steps
1. **准备阶段**：明确研究目标，选择3-5个典型用户，设计半结构化访谈提纲，准备记录工具
2. **观察（Observe）**：进入用户真实环境，像"影子"一样跟随用户，记录行为细节。重点观察：反复出现的行为模式、用户与环境的互动、用户表达困难或不满的瞬间
3. **沉浸（Immerse）**：亲自体验用户的生活场景（如使用用户的产品一整天、走用户的通勤路线）。记录自己的感受和发现
4. **访谈（Interview）**：在真实场景中进行对话，避免引导性问题。核心问题："能给我讲讲你平时是怎么做的？""最让你烦的是什么？""你为什么这样做而不是那样做？"
5. **记录（Document）**：用照片、视频、速写、文字多形式记录。每个观察都标注时间、场景、用户情绪状态
6. **分析与洞察**：整理田野笔记，寻找行为模式、矛盾点（说的vs做的）、适应性行为（用户自己发明的解决方案）。提炼5条以上关键洞见
7. **转化为设计机会**：将洞见转化为具体的设计方向或产品机会

## Cases
1. **宜家厨房产品研究**：宜家的设计团队进入中国家庭厨房进行民族志研究，发现中国主妇在烹饪时需要同时处理3-4道菜，但西方设计的厨房动线只考虑一道菜。洞见催生了"多灶台并行操作"的厨房模块设计，成为宜家中国区爆款。
2. **银行网点服务重设计**：某银行通过民族志发现，老年客户来网点不仅是为了办业务，更是为了"有人聊聊"。将"社交需求"纳入服务设计，在等候区增加茶水和聊天角，老年客户满意度提升35%，同时减少了柜员被"闲聊"占用的时间。

## Limitations
- 样本量小（3-5人），结论的普适性有限
- 研究者自身的偏见可能影响观察和解读
- 耗时耗力，不适合快速决策场景
- 用户在被观察时可能改变行为（霍桑效应）
- 洞见难以量化，向决策层汇报时需要更强的叙事能力

## Method Relations
- **前置方法**：用户画像（user-persona）——民族志研究前的假设构建
- **后续方法**：亲和图（CG18）——对民族志获得的大量观察进行分类整理；客户旅程（customer-journey）——将洞见映射到用户旅程的关键节点
- **互补方法**：设计思维（design-thinking）——民族志是设计思维"共情"阶段的核心方法
- **对比方法**：与定量调研对比——民族志回答"为什么"，定量调研回答"有多少"

## Prompt
你是一位设计民族志研究专家。请针对以下研究主题，模拟执行设计民族志分析：

**研究主题**：[用户填写]
**目标用户群体**：[用户填写]
**研究场景**：[用户填写]

请按以下步骤执行：
1. 基于对该用户群体和场景的理解，构建3个典型用户画像（简短代号+特征）
2. 为每个用户模拟一段田野观察记录（包含场景描述、行为细节、用户原话、研究者感受）
3. 从观察中提炼行为模式（反复出现的行为、矛盾点、适应性行为）
4. 基于"说的vs做的"矛盾，产出至少5条关键洞见
5. 将洞见转化为具体的设计机会，评估可行性

注意：模拟的田野笔记应尽可能真实、有细节感，包含感官描述（声音、气味、空间、光线），体现"走进用户世界"的感觉。

输出格式请严格按照Output Format要求。
