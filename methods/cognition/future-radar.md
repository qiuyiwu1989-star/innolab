# 未来雷达图（Future Radar）

## Meta
- ID: CG15
- Engine: Cognition
- Layer: L4
- Origin: classic

---

## Definition
未来雷达图是一种系统化的趋势扫描工具，从技术、社会、经济、环境、政治五个维度全面扫描未来趋势，通过雷达图可视化呈现各维度趋势的强度和影响力，帮助团队识别高影响力趋势并聚焦资源。

## Core Idea
单一维度的趋势分析容易遗漏关键信号。通过五维度雷达扫描，可以在看似无关的趋势之间发现交叉影响，找到真正值得投入的未来方向。雷达图的形状本身就是战略信息——哪个维度突出、哪个维度凹陷，反映了你的战略重心和盲区。

## Use Cases
- 企业制定3-5年战略规划前的趋势研判
- 新产品立项前的外部环境扫描
- 投资决策前的宏观趋势评估
- 行业变革期的机遇识别
- 团队对未来方向产生分歧时的共识建立

## Input
- 分析的时间范围（如：未来3年、未来5年）
- 关注的行业或领域
- 可选：已有的趋势信号或初步判断

## Output
- 五维度趋势雷达图（可视化）
- 每个维度的Top 3高影响力趋势清单
- 跨维度交叉影响分析
- 优先关注趋势排序（按影响力×确定性）

## Steps
1. **确定扫描范围**：明确时间窗口（如2026-2030）和关注领域
2. **五维度扫描**：分别从技术（T）、社会（S）、经济（E）、环境（E）、政治（P）五个维度列出观察到的趋势信号
3. **趋势评估**：对每条趋势评估两个指标——影响力（1-5分）和确定性（1-5分）
4. **绘制雷达图**：以五维度为轴，将各维度最高影响力趋势的得分绘制成雷达图
5. **交叉分析**：检查不同维度趋势之间的关联和叠加效应
6. **聚焦排序**：按"影响力×确定性"排序，识别Top 5值得优先关注的趋势
7. **产出行动建议**：针对高优先级趋势，提出具体的战略响应建议

## Output Format
```

## 雷达图
[五维度雷达图可视化，每维度标注最高影响力趋势]

## 维度详情

| 趋势 | 影响力 | 确定性 | 优先级 |
|------|--------|--------|--------|
| ... | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | 🔴高 |
```

## Cases
1. **新能源车企2027-2030趋势研判**：某新能源车企用未来雷达图扫描发现，技术维度的固态电池突破（影响力5/确定性3）和政策维度的碳关税扩展（影响力4/确定性4）形成交叉影响，决定提前布局固态电池供应链，同时建立碳足迹追踪系统。
2. **教育科技公司战略调整**：一家在线教育公司通过雷达图发现，社会维度的"AI焦虑"趋势（影响力4/确定性5）与技术维度的AI个性化学习（影响力5/确定性4）形成矛盾张力，据此调整产品定位为"AI辅助的人类导师"而非"AI替代教师"。

## Limitations
- 趋势评估依赖主观判断，不同团队成员可能给出差异很大的评分
- 雷达图的五维度划分可能遗漏某些重要维度（如文化、军事）
- 跨维度交叉影响的分析深度受限于团队的知识广度
- 对"黑天鹅"事件（低确定性但极高影响力）的捕捉能力有限

## Method Relations
- **前置方法**：PEST分析（DC02 SWOT中的外部环境部分）、行业扫描
- **后续方法**：战略路线图（ST14）、蓝海战略（blue-ocean）——用雷达图识别的趋势作为战略规划的输入
- **互补方法**：情景规划——对雷达图中低确定性高影响力的趋势做情景推演
- **对比方法**：与SWOT的"机会/威胁"分析互补，雷达图更系统化和可视化

## Prompt
你是一位趋势分析专家。请针对以下领域和时间范围，执行未来雷达图分析：

**领域**：[用户填写]
**时间范围**：[用户填写]

请按以下步骤执行：
1. 从技术（T）、社会（S）、经济（E）、环境（E）、政治（P）五个维度扫描趋势信号，每维度至少列出3条趋势
2. 对每条趋势评估影响力（1-5）和确定性（1-5）
3. 用文本绘制五维度雷达图（用柱状图或星级表示各维度综合得分）
4. 分析跨维度的交叉影响（至少找出2组）
5. 按"影响力×确定性"排序，给出Top 5优先关注趋势
6. 针对Top 5趋势各给出一条具体行动建议
7. 做盲区检查：我们可能忽视了什么？

输出格式请严格按照Output Format要求。
