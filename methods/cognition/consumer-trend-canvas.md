# 消费趋势画布（Consumer Trend Canvas）

## Meta
- ID: CG16
- Engine: Cognition
- Layer: L3
- Origin: classic

---

## Definition
消费趋势画布是一个结构化的趋势洞察工具，通过"趋势→需求→表现→机会→评估"五个环节，将模糊的消费趋势转化为具体的产品和商业机会。它帮助团队从纷繁的市场信号中提炼出可行动的创新方向。

## Core Idea
趋势本身不创造价值，从趋势到机会的转化链条才是关键。消费趋势画布的核心是建立一条清晰的因果链：这个趋势背后的真实需求是什么？它在消费行为中如何表现？我们能从中捕捉什么机会？这个机会值不值得投入？

## Use Cases
- 新消费品牌寻找品类机会
- 产品团队进行年度趋势复盘和机会梳理
- 市场研究部门将趋势报告转化为行动建议
- 创业者验证市场方向
- 品牌升级前的消费洞察梳理

## Input
- 目标消费群体（如Z世代、新中产、银发族）
- 关注的消费领域（如食品饮料、家居、出行）
- 已有的趋势信号（可来自社交媒体、行业报告、用户访谈等）

## Output
- 消费趋势画布（完整的五环节分析）
- Top 3可行动机会清单
- 每个机会的初步可行性评估

## Steps
1. **趋势捕捉**：列出观察到的消费趋势信号（至少5条），注明信号来源
2. **需求解构**：对每条趋势追问"消费者真正想要的是什么？"，提炼底层需求
3. **行为表现**：描述该需求在实际消费行为中的具体表现（购买行为、使用场景、社交表达等）
4. **机会映射**：将需求与行为表现转化为具体的产品/服务/体验机会
5. **机会评估**：从市场规模、竞争强度、自身能力匹配度、时间窗口四个维度评估每个机会
6. **优先排序**：选出Top 3机会，给出启动建议

## Cases
1. **新茶饮品牌趋势洞察**：某新茶饮品牌使用消费趋势画布发现"成分透明化"趋势背后的底层需求是"掌控感"，行为表现为消费者主动查看配料表并拍照分享。据此推出"配料可视化"系列——将茶叶产地、冲泡参数印在杯身，首月销量增长40%。
2. **家居品牌银发市场**：一家家居公司通过画布分析银发族"适老化改造"趋势，发现表层需求是"安全"，底层需求是"不失去对家的掌控权"。机会不是"老人专用产品"，而是"让现有家居变得更好用的配件"，推出模块化适老配件系列。

## Limitations
- 趋势信号的收集受限于团队的信息渠道广度
- "底层需求"的提炼依赖分析者的洞察力，可能存在偏差
- 画布是静态快照，消费趋势变化快，需要定期更新
- 对B2B消费场景的适用性较弱

## Method Relations
- **前置方法**：设计民族志（CG17）——用田野观察获得的一手数据作为趋势信号输入
- **后续方法**：用户画像（user-persona）——将机会对应到具体用户画像；客户旅程（customer-journey）——设计机会的落地触点
- **互补方法**：KANO模型（kano）——对识别出的需求做基本/期望/兴奋分类
- **对比方法**：与商业模式画布（BMC）的关系——趋势画布聚焦消费洞察端，BMC聚焦商业架构端

## Prompt
你是一位消费趋势分析师。请针对以下消费群体和领域，执行消费趋势画布分析：

**消费群体**：[用户填写]
**领域**：[用户填写]
**已知趋势信号**：[用户填写，可选]

请按以下步骤执行：
1. 列出至少5条消费趋势信号（如果用户未提供，请基于对该领域的了解推断），注明信号来源和强度
2. 对每条趋势进行需求解构：表层需求是什么？底层需求是什么？属于功能/情感/社会哪类需求？
3. 描述每条需求在消费行为中的具体表现
4. 将需求映射为产品/服务/体验三类机会
5. 从市场规模、竞争强度、能力匹配、时间窗口四维度评估每个机会（1-5分）
6. 给出Top 3机会及启动建议

输出格式请严格按照Output Format要求。
