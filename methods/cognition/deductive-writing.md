# 推导式写作法（Deductive Writing）

## Meta
- ID: CG13
- Engine: Cognition

## Definition（一句话定义）

引入→背景→分析→推演→收束五段推导链，核心是让读者"跟着一起推导出结论"而非被灌输观点。

## Core Idea（核心思想）

推导式写作的核心不是"表达观点"，而是**还原思考过程**。读者体验的不是"被说服"，而是"自己推导出了结论"。每段是上一段的必然结果，不能随意调换顺序。

## Use Cases（适用场景）

- 深度分析文章（4000-5000字）
- 面向创业者/管理者的认知升级内容
- 需要让读者"跟上思路"的复杂议题

## Steps（使用步骤）

1. **引入**：提出一个引人注意的现象或问题
2. **背景**：交代上下文，让读者进入语境
3. **分析**：拆解问题的结构和因果关系
4. **推演**：基于分析推导出必然结论
5. **收束**：回到现实，给出行动方向

## 核心原则

- 每段是上一段的必然结果，不能随意调换顺序
- 禁止"一二三"并列罗列，必须用因果推导
- 五种论证移动方式：层层递进、现象溯因、预期颠覆、历史类比、两元对比

## 篇幅标准

4000-5000字，面向有认知升级需求的创业者/管理者

## Pitfalls（注意事项/常见误区）

- 不是议论文，不能先亮结论再论证——要让结论自然"推导出来"
- 五段顺序不可调换，调换了就变成并列罗列
- "分析"段不能跳过，否则"推演"缺乏逻辑基础

## Deep Understanding（深度理解）

- 与 GN06 路演法的区别：推导写作偏线性论证（一篇文章一个推导链），路演法偏节奏感叙事（9页结构，有认知反转节点）
- 与 CG12 金字塔原理的区别：金字塔是"自上而下表达"，推导写作是"自下而上推导"
- 高阶用法：推导写作完成后的文章，可作为 GN06 路演法的素材输入，将推导链转化为路演叙事
