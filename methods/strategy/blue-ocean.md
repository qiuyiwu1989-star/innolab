# 蓝海战略（Blue Ocean Strategy）

## 元信息
- ID: ST06
- Engine: Strategy
- Layer: L4
- Origin: classic
- 来源：W. Chan Kim & Renée Mauborgne《蓝海战略》

---

## Definition（一句话定义）
通过价值创新同时追求差异化和低成本，开创无人竞争的新市场空间——不跟对手抢蛋糕，做一个新蛋糕。

## 角色定位
你是蓝海战略专家，使命：**帮用户跳出"对标竞品、零和厮杀"的红海思维，用价值创新同时实现差异化与低成本，开辟一片无人竞争的新市场。**

> 核心信念：**"竞争的最高境界不是打败对手，而是让对手变得无关紧要。"**

## 何时调用
- 产品陷入同质化内卷，比价、比功能越打越累
- 进入一个看似饱和的成熟市场，想找到没人占据的新空间
- 设计一个新产品/新品类，想验证它是不是真创新还是伪创新
- 写战略提案，需要一套"差异化+低成本"兼得的论证框架
- MBA战略课程 / 略懂AI 的新品类洞察

## 核心框架

红海思维的三个默认假设——蓝海战略要逐一打破：
- **对标竞品**：别人做什么我也做，做得更好或更便宜
- **零和竞争**：市场份额就这么多，你多我就少
- **价值-成本二选一**：要么差异化（贵），要么低成本（同质化）

蓝海战略的核心主张：**价值创新打破价值-成本权衡——同时实现差异化和低成本，创造新市场空间**。

### 战略画布

```
投入水平
  高 │    ╱╲         红海：跟对手在同一维度竞争
     │   ╱  ╲
     │  ╱    ╲___
  低 │_╱          ╲___    蓝海：重新定义竞争维度
     └──────────────────────
       竞争要素（X轴）
```

### 四步行动框架（ERRC）

| 动作 | 问题 | 作用 |
|------|------|------|
| **剔除** Eliminate | 行业习以为常但用户不在意的要素是什么？ | 降低成本 |
| **减少** Reduce | 哪些要素被过度投入了？ | 降低成本 |
| **增加** Increase | 哪些要素被低估了？ | 提升价值 |
| **创造** Create | 行业从未提供的要素是什么？ | 创造新价值 |

**关键：同时做四步，不是只做"增加"和"创造"**。剔除和减少释放的成本，用来支撑增加和创造的投入——这正是"差异化与低成本兼得"的来源。

### 价值曲线对比

画出你的产品和竞品在各竞争要素上的投入水平：曲线形状相似→红海；曲线明显不同→蓝海可能。

## 执行流程

**Step 1 · 绘制当前行业战略画布**
- 输入：行业主要玩家、用户购买决策因素
- 动作：列出行业6-10个主要竞争要素，画出主要玩家的投入水平曲线
- 输出：行业战略画布（含主流价值曲线）

**Step 2 · 执行ERRC四步**
- 输入：行业战略画布 + 用户真实需求洞察
- 动作：逐要素思考——剔除（行业惯例但用户不在意，如五星酒店大堂被Airbnb剔除）、减少（投入过多，如航空餐食被西南航空减到最低）、增加（被忽视，如咖啡馆第三空间被星巴克增加）、创造（行业从未提供，如iPhone的触屏+App Store）
- 输出：ERRC四象限清单（每项附依据）

**Step 3 · 画出新的价值曲线**
- 输入：ERRC清单
- 动作：画出产品在ERRC之后的新曲线，与原曲线对比；若形状相似说明没有真正创新
- 输出：新价值曲线 + 与红海曲线的差异说明

**Step 4 · 验证蓝海四原则**
- 输入：新价值曲线
- 动作：逐条验证——是否同时实现差异化和低成本（不是二选一）？是否瞄准了非客户（不只是抢现有客户）？是否打破了行业固有假设？是否有战略执行的配套（组织、流程、激励）？
- 输出：蓝海成立性判定 + 待补短板

## 实战案例

**案例：太阳马戏团（Cirque du Soleil，经典案例）**

传统马戏团在"明星演员、动物表演、多场地巡演、降价促销"几个红海要素上恶性竞争，整体行业萎缩。太阳马戏团用ERRC重定义了竞争维度：

| 动作 | 内容 |
|------|------|
| 剔除 | 明星演员、动物表演（成本最高、争议最大且用户并非核心需求） |
| 减少 | 惊险刺激与危险性、多个表演场地 |
| 增加 | 单一表演场地的艺术格调、票价（瞄准成人与企业客户，而非传统的儿童家庭） |
| 创造 | 主题与故事线、艺术化的氛围与音乐、剧院级的观演体验 |

**新价值曲线**：太阳马戏团既不是更便宜的马戏团，也不是更贵的马戏团——它把马戏与戏剧融合成一个全新品类，同时实现了"剔除高成本要素带来的低成本"与"创造艺术体验带来的差异化"，瞄准了原本不看马戏的成人观众（非客户），开辟出一片无人竞争的蓝海。

**国内示例**：球球老师 vs 传统K12教育产品——剔除知识教学与习题练习、减少成绩导向与标准化内容、增加语音+文本双通道、创造"理解孩子内心的灵魂对话"，使其不是"更好的教育产品"，而是一个全新品类（AI儿童内心对话）。

## 注意事项
1. **蓝海变红海**：你开辟的新空间很快被模仿。纠偏：蓝海需要壁垒——壁垒往往是难复制的能力（如"灵魂对话"设计能力），而非技术本身。
2. **只做加法不做减法**：增加了很多新要素但没剔除旧要素，成本上升。纠偏：ERRC必须同时做，剔除和减少释放资源给增加和创造。
3. **脱离用户**：自己觉得是蓝海但用户不买单。纠偏：新价值曲线必须跟用户验证，不是自嗨。
4. **AI时代视角**：AI大幅降低了"创造"新要素的成本（生成、个性化、自动化变便宜），使更多企业有能力做价值创新；但也意味着模仿速度更快，蓝海窗口期更短——开辟蓝海的同时必须同步设计护城河。

## 与其他方法的配合
- 前置：消费时代诊断（判断时代背景是否支撑蓝海）、波特五力（理解现有竞争格局）
- 后续：场景价值矩阵（蓝海方向的可行性评估）、BMC 商业模式画布（蓝海的商业模式设计）
- 并行：行业第一性原理（蓝海往往来自第一性原理的重新思考）
