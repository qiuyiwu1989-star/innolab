# ST18 系统因果回路分析

> 归属：🧠 认知引擎 · L4（系统层）
> 来源：Systems Thinking 技能 · 因果回路图模板
> 触发词：因果分析、画连接、反馈循环、找根因、系统怎么运转

---

## 定义

因果回路分析是把一个系统里的关键要素画成连接图，识别正反馈（放大）和负反馈（稳定）循环，从而理解系统行为的方法。

## 核心概念

### 正反馈循环（Reinforcing Loop / R）

**特征：** 越滚越大，雪球效应
- 增长：收入↑ → 投资↑ → 产能↑ → 收入↑
- 崩溃：信任↓ → 沟通↓ → 误会↑ → 信任↓

### 负反馈循环（Balancing Loop / B）

**特征：** 自我调节，趋于平衡
- 体温调节：体温↑ → 出汗↑ → 散热↑ → 体温↓
- 市场均衡：价格↑ → 需求↓ → 价格↓

### 延迟（Delay）

**特征：** 原因和结果之间有时间差
- 投入 → 延迟 → 效果显现
- 这是最容易导致错误决策的因素

## 分析流程

```
Step 1：界定系统
  → 关键要素有哪些？（5-10个）
  → 系统边界在哪里？
  → 这个系统在更大系统里是什么位置？

Step 2：画连接
  → A变化时，B是同向还是反向变化？
  → 标注：+（同向）/ -（反向）

Step 3：找循环
  → 从任意要素出发，顺着连接走一圈回到起点
  → 判断：偶数个-号 = 正反馈（R）/ 奇数个-号 = 负反馈（B）

Step 4：识别延迟
  → 哪些连接之间有明显的时间延迟？
  → 延迟最容易导致"过度反应"或"反应不足"

Step 5：判断系统主导行为
  → 当前系统由哪个循环主导？
  → 正反馈主导 → 指数增长或崩溃
  → 负反馈主导 → 趋于稳定或僵化
```

## 输出模板

```
📊 系统名称：[XXX]

关键要素：
1. [要素A]
2. [要素B]
3. [要素C]
...

反馈循环：
🔄 R1（正反馈）：[A]↑ → [B]↑ → [C]↑ → [A]↑
   "这个循环在放大什么？"
⚖️ B1（负反馈）：[D]↑ → [E]↓ → [F]↑ → [D]↓
   "这个循环在稳定什么？"

⏰ 关键延迟：
- [X] → [Y] 存在约 [N天/月] 的延迟
- 后果：可能导致 [过度反应/反应不足]

主导判断：
当前系统由 [R1/B1] 主导，表现为 [增长/稳定/振荡/崩溃]

杠杆点：
- 干预 [某个要素]，可以 [增强/削弱] [某个循环]
- 注意 [某个延迟]，避免 [错误决策类型]
```
