# 战略路线图（Strategy Roadmap）

## Meta
- ID: ST14
- Engine: Strategy
- Layer: L4
- Origin: classic

---

## Definition

战略路线图是一种为短期、中期、长期策略制定创新路径的方法，通过三层时间维度规划关键里程碑和具体行动，让战略愿景落地为可执行的行动序列。

## Core Idea

"愿景是终点，路线图是路径。"战略路线图的核心不是画一张漂亮的图，而是**让"未来3年怎么做"变成每个季度都能check的清单**。

## Use Cases

- 制定创新战略规划
- 规划产品发展路径
- 协调团队资源的时序分配
- 向投资人/管理层展示战略方向
- 年度/季度规划会使用

## Input

- 战略愿景（想要达到的终态）
- 当前状态（起点）
- 可用资源（人、钱、时间）
- 外部约束（市场窗口、竞争压力）

## Output

- 三层时间维度的路线图
  - 短期（0-1年）：具体行动+季度里程碑
  - 中期（1-3年）：关键验证+扩展策略
  - 长期（3-5年）：战略愿景+颠覆式创新方向
- 关键决策节点标注
- 风险/假设清单

## Steps

1. **定义终点**：3-5年后希望达到什么状态？（用具体指标描述）
2. **评估起点**：现在在哪？有什么资源？有什么短板？
3. **识别关键里程碑**：从终点倒推，每个阶段必须达到什么？
4. **规划短期行动**：0-1年具体做什么，按季度拆分
5. **设计中期验证**：1-3年需要验证哪些关键假设
6. **描绘长期愿景**：3-5年的战略方向和可能的颠覆点
7. **标注决策节点**：哪些节点需要做Go/No-go决策？
8. **识别依赖关系**：哪些行动依赖其他行动先完成？

## Output Format

```

起点：[当前状态]
```

## Cases

**案例1：AI教育创业公司**
愿景：成为K12 AI教育领域的头部品牌。
- 短期：先做一款爆款课程验证PMF（Q1课程上线，Q2获取1000付费用户，Q3迭代至留存率>40%，Q4实现单课程盈亏平衡）
- 中期：扩展到3-5门课程，建立教师IP矩阵，搭建社区
- 长期：成为AI教育内容平台，连接教师和学生
关键决策点：Q4如果留存率<30%，转向2B方向。

**案例2：传统制造企业AI转型**
愿景：实现生产全流程智能化。
- 短期：选1条产线做AI质检试点（0-6月），验证ROI后扩展到3条线（6-12月）
- 中期：覆盖全工厂，建立数据中台，培养内部AI团队
- 长期：输出AI能力给供应链上下游，从成本中心变利润中心

## Limitations

- 长期规划在快速变化的市场中容易过时
- 路线图可能造成"计划幻觉"——以为计划了就等于做到了
- 忽略了组织内部的执行阻力和变革成本
- 过于线性，难以应对突变和黑天鹅

## Prompt

你是一位战略规划顾问。用户会给出一个战略目标或业务方向，请帮他们：

1. 定义清晰的3-5年战略愿景（用具体指标）
2. 评估当前起点状态
3. 按短期(0-1年按季度)/中期(1-3年)/长期(3-5年)三层规划路线
4. 标注每个阶段的关键里程碑
5. 识别关键决策节点（什么条件下Go/No-go）
6. 列出需要验证的关键假设和主要风险

要求：路线要具体可执行，避免"加强品牌建设"这类空话。每个里程碑要能被明确判断"做到了/没做到"。
