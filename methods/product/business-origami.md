# 商业折纸（Business Origami）

## Meta
- ID: PD13
- Engine: Product
- Layer: L3
- Origin: classic

---

## Definition
商业折纸是一种用纸质标志（纸片、积木、贴纸等实体道具）在桌面上建立商业系统物理模型的方法。通过摆放和移动这些道具，团队可以可视化商业模式中的角色、流程、渠道和关系，发现隐藏的瓶颈和机会。

## Core Idea
抽象的商业模式用语言讨论容易各说各话，但当你把每个角色、每个渠道、每个流程用一个实体纸片摆在桌上时，所有人都能看到同一个画面。商业折纸的力量在于"让隐性系统显性化"——纸片之间的空间和连线本身就在说话。

## Use Cases
- 商业模式设计和迭代工作坊
- 跨部门协作中的流程可视化
- 用户旅程中的痛点定位
- 新业务/新渠道的规划推演
- 向非专业人士解释复杂商业模式

## Input
- 商业模式的基本要素（角色、产品、渠道、收入来源等）
- 参与者（建议4-8人跨职能团队）
- 实体道具：不同颜色/形状的纸片代表不同要素
  - 圆形 = 用户/客户
  - 方形 = 产品/服务
  - 三角形 = 渠道/触点
  - 星形 = 收入/价值
  - 箭头 = 关系/流向

## Output
- 商业系统的物理模型照片/描述
- 关键关系和瓶颈识别
- 优化方案（通过移动/增加/删除纸片实现）

## Steps
1. **准备道具**：准备不同颜色和形状的纸片，定义每种形状的含义。在大桌面上划定"前台"（用户可见）和"后台"（用户不可见）区域
2. **角色放置**：将代表不同用户角色的圆形纸片放在桌面，标注角色名
3. **产品与服务放置**：用方形纸片代表核心产品/服务，放在角色附近
4. **渠道连接**：用三角形纸片和箭头连线表示用户如何触达产品
5. **价值流动**：用箭头和星形纸片标注价值（钱、数据、服务）的流动方向
6. **审视与发现**：全团队一起观察桌面模型，找瓶颈（箭头堆积处）、断点（没有连线的孤岛）、冗余（重复的渠道）
7. **优化推演**：通过移动、增加、删除纸片来模拟商业模式的调整，拍照记录每次变化

## Cases
1. **星巴克多渠道体验优化**：星巴克团队用商业折纸可视化"到店/外卖/零售/电商"四条渠道，发现零售渠道（超市货架上的星巴克）与品牌体验渠道（门店）之间没有连接箭头——买超市咖啡的用户从不进店。优化方案：在零售包装上增加门店体验券，打通两个渠道。
2. **医院就诊流程再造**：一家医院用商业折纸模拟患者就诊流程，发现"挂号→候诊→就诊→缴费→取药"流程中，缴费环节（星形纸片）挡在就诊和取药之间，形成物理瓶颈。通过移动星形纸片到后台（自动扣费），前台流程缩短40%。

## Limitations
- 实体道具操作不适合远程团队（数字化工具可缓解但丢失了触感优势）
- 过于复杂的商业模式（多边市场、平台生态）可能让桌面变得混乱
- 模型的准确性依赖参与者对业务的理解深度
- 静态纸片难以表达动态变化（如随时间变化的用户行为）

## Method Relations
- **前置方法**：商业模式画布（BMC / PD01）——先用BMC梳理要素，再用商业折纸可视化
- **后续方法**：客户旅程（customer-journey）——折纸发现的瓶颈可以展开为客户旅程的详细分析
- **互补方法**：故事板（GN12）——折纸关注系统结构，故事板关注用户叙事，两者互补
- **对比方法**：与商业模式画布对比——BMC是二维表格（静态描述），折纸是三维空间（动态关系可视化）

## Prompt
你是一位商业模式可视化专家。请对以下商业系统执行商业折纸分析：

**企业/项目**：[用户填写]
**商业模式简述**：[用户填写]
**参与角色**：[用户填写]

请按以下步骤执行：
1. 识别商业模式中的核心要素：用户角色（⭕）、产品/服务（⬜）、渠道/触点（🔺）、价值/收入（⭐）
2. 用文字描述桌面布局（哪个纸片在什么位置，纸片之间的连线关系）
3. 描述核心价值流（从用户到产品到收入的完整路径）
4. 识别关键瓶颈（连线密集处或断点）
5. 发现隐藏机会（未被连接的潜在关系）
6. 给出优化方案（增加/移动/删除纸片的具体操作及预期效果）

注意：用emoji和文字可视化描述布局，让人能"看到"桌面模型。

输出格式请严格按照Output Format要求。
