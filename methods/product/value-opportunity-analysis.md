# 价值机会分析（Value Opportunity Analysis）

## Meta
- ID: PD12
- Engine: Product
- Layer: L3
- Origin: classic

---

## Definition
价值机会分析是一种评估产品情感价值的工具，从情感、美学、身份、影响力、核心品质五个维度系统评估产品带给用户的深层价值体验，帮助发现超越功能的差异化机会。

## Core Idea
产品竞争的终极战场不在功能参数，而在用户的情感体验。当功能趋同时，决定用户选择的是"这个产品让我感觉如何"——它是否触动了我的情感、是否符合我的审美、是否让我有身份认同感、是否让我觉得在做有意义的事。

## Use Cases
- 产品同质化严重时寻找差异化突破口
- 品牌升级前评估产品的情感价值基线
- 设计方案评审时补充情感维度
- 竞品对比中挖掘情感价值差异
- 产品定价策略中支撑溢价的价值论证

## Input
- 产品描述（功能、设计、定位）
- 目标用户画像
- 竞品信息（至少2个竞品）
- 可选：用户反馈数据

## Output
- 五维度价值机会评估表
- 价值优势和劣势分析
- Top 3价值机会点
- 差异化价值主张建议

## Steps
1. **维度定义**：明确五个价值维度的含义和评估标准
   - 情感（Emotion）：产品唤起的情感体验（快乐、安心、自豪、惊喜等）
   - 美学（Aesthetics）：视觉、触觉、听觉等感官体验
   - 身份（Identity）：产品如何帮助用户表达自我和社会身份
   - 影响力（Impact）：产品对用户生活/社会的正面影响感
   - 核心品质（Core Quality）：产品基础功能的可靠性和完成度
2. **用户价值映射**：针对目标用户，分析每个维度对他们的重要程度（1-5分）
3. **产品价值评估**：对自身产品在每个维度的表现评分（1-5分）
4. **竞品对标**：对2-3个竞品做同样评估
5. **机会识别**：找"用户重视但所有产品都做不好"的维度（价值洼地）
6. **价值主张设计**：基于机会点设计差异化的价值主张

## Cases
1. **无印良品的价值机会**：在快时尚品牌追求"潮流感"（身份维度）时，无印良品发现"不被潮流绑架"本身就是一种身份表达。美学维度做到极致（极简设计），身份维度反其道行之（"不需要Logo"的身份感），在两个维度形成独特价值组合。
2. **Patagonia的影响力溢价**：户外品牌Patagonia发现用户极度重视"影响力"维度（环保意识），但行业普遍忽视。通过"Don't Buy This Jacket"反消费主义营销和终身维修服务，在影响力维度做到极致，支撑了高于竞品50%的定价。

## Limitations
- 五维度的权重因用户群体差异很大，需要针对细分人群分别评估
- 情感和美学维度的评估高度主观，缺乏统一标准
- 框架更适合消费品类，对B2B/工业品的适用性较弱
- 价值感知随时间变化，需要定期重新评估

## Method Relations
- **前置方法**：用户画像（user-persona）——明确目标用户后才能评估价值权重；消费趋势画布（CG16）——识别消费趋势中蕴含的价值机会
- **后续方法**：品牌共鸣模型（brand-resonance）——价值机会分析识别的差异化方向可通过品牌共鸣模型落地
- **互补方法**：创新十环分析（PD11）——十环找创新维度，价值分析找情感价值，两者结合形成立体创新策略
- **对比方法**：与KANO对比——KANO关注功能层面的需求分类，价值机会关注情感层面的价值体验

## Prompt
你是一位产品价值分析专家。请对以下产品执行价值机会分析：

**产品**：[用户填写]
**目标用户**：[用户填写]
**竞品**：[用户填写]
**产品简述**：[用户填写]

请按以下步骤执行：
1. 分析目标用户在五个价值维度（情感、美学、身份、影响力、核心品质）的重视度（1-5分），说明用户在每个维度的核心诉求
2. 对我方产品在五个维度评分（1-5分），给出具体表现描述
3. 对2-3个竞品做同样评估
4. 找出"用户重视但行业表现差"的价值洼地（机会点）
5. 找出"我方明显优于竞品"的价值优势
6. 基于机会点和优势，设计差异化价值主张

输出格式请严格按照Output Format要求。
