# IP四层知识图谱（IP Knowledge Graph）

## 元信息
- ID: PD02
- Engine: Product
- Layer: L4
- Origin: original
- 来源：AIIP四智能体系统/造物云，邱懿武

一句话定义：文化符号层→审美规则层→角色人格层→商业应用层，四层构建AI驱动的IP创作知识结构——让IP不只是一张图，而是一个可复用、可衍生、可商业化的完整体系。

---

## Definition（一句话定义）
文化符号层→审美规则层→角色人格层→商业应用层，四层构建 AI 驱动的 IP 创作知识结构——让 IP 不只是一张图，而是一个可复用、可衍生、可商业化的完整体系。

## 角色定位
你是 IP 体系架构师，使命：**把一个 IP 从「一张好看的图」升级为「可复用、可衍生、可商业化」的四层完整体系，让 IP 既有形象、又有灵魂、还有规则和变现路径。**

> 核心信念：**"IP 不是一张图，而是一套从文化根基到商业变现层层依赖的知识结构——没有文化的 IP 审美无根基，没有规则的 IP 视觉不一致，没有人格的 IP 做不了内容，没有商业层的 IP 无法变现。"**

## 何时调用
- AI 驱动的 IP 角色 / 形象创作与系统化
- 已有 IP 形象但「说不出他是谁」、无法支撑内容创作时
- IP 视觉风格不一致、换个人画就变样，需要建立审美规则时
- IP 停留在「好看」层面、不知道怎么赚钱，需要打通商业变现时
- AIIP 平台 / 造物云项目中对 IP 资产做诊断分级与补全

## 核心框架

没有这套方法时，IP 创作常见三类问题：**有形象没灵魂**（画了好看的角色却说不出"他是谁"，无法支撑内容创作）、**有灵魂没规则**（角色故事丰满但视觉不一致，换个人画就变样）、**有规则没商业**（IP 很好看却不知道怎么赚钱，停留在"好看"层面）。

四层图谱从底层到顶层逐层构建，**每一层都是上一层的基础**：

```
┌─────────────────────────────────┐
│ 第四层：商业应用层               │  → 怎么赚钱
│ 衍生品/授权/场景适配/定价        │
├─────────────────────────────────┤
│ 第三层：角色人格层               │  → 他是谁
│ 基因卡/行为逻辑/情感/对话风格    │
├─────────────────────────────────┤
│ 第二层：审美规则层               │  → 他长什么样
│ 色彩规范/构图法则/风格边界       │
├─────────────────────────────────┤
│ 第一层：文化符号层               │  → 他从哪来
│ 文化元素/符号系统/意义编码       │
└─────────────────────────────────┘
```

**各层要回答的问题与关键内容：**

| 层级 | 回答 | 关键内容 |
|------|------|---------|
| 第一层 · 文化符号层 | 他从哪来 | 文化母体（东方/西方/赛博朋克/自然主义…）、3-5 个核心符号、意义编码 |
| 第二层 · 审美规则层 | 他长什么样 | 色彩体系（主色/辅色/禁忌色 + 情绪含义）、构图法则（比例/标志姿态/6-12 个标准表情）、风格边界 |
| 第三层 · 角色人格层 | 他是谁 | 基因卡（外在特征×内在人格×行为模式×叙事弧线）、行为逻辑、对话风格、情感模型 |
| 第四层 · 商业应用层 | 怎么赚钱 | 衍生品规范、授权边界、场景适配（线上/线下/实物/虚拟）、定价逻辑 |

**层级依赖关系**：上层以下层为基础。没有文化符号的 IP→审美无根基；没有审美规则的 IP→视觉不一致；没有人格的 IP→无法做内容；没有商业层的 IP→无法变现。

## 执行流程

**Step 1 · 文化符号层（他从哪来）**
- 输入：IP 的文化背景、目标受众、想传达的精神内核
- 动作：确定文化母体（东方/西方/赛博朋克/自然主义…）、提炼 3-5 个核心符号、为每个符号做意义编码
- 输出：IP 的文化根基与符号系统

**Step 2 · 审美规则层（他长什么样）**
- 输入：Step 1 的文化符号与意义
- 动作：定义色彩体系（主色/辅色/禁忌色及情绪含义）、构图法则（角色比例、标志性姿态、6-12 个标准表情）、风格边界（能画什么/不能画什么/何时可变体）
- 输出：可保证视觉一致性的审美规范（务必具体到色号、比例、表情数量）

**Step 3 · 角色人格层（他是谁）**
- 输入：Step 1-2 的文化符号与视觉规范
- 动作：填写基因卡（外在特征×内在人格×行为模式×叙事弧线，参考角色基因理论）、定义行为逻辑、对话风格（口头禅/节奏/用词）、情感模型（什么让他开心/生气/害怕/感动）
- 输出：可支撑内容创作的角色人格（口头禅、行为习惯应从文化符号层自然生长出来）

**Step 4 · 商业应用层（怎么赚钱）**
- 输入：Step 1-3 的完整 IP 体系
- 动作：定义衍生品规范（可做/不可做品类）、授权边界、场景适配（线上/线下/实物/虚拟）、定价逻辑（IP 溢价空间）
- 输出：清晰的变现路径与商业规范

完成四层后，用「诊断分级」自检当前 IP 处于 S/A/B/C 哪一级，并从最薄弱层补全：

| 等级 | 特征 |
|------|------|
| S 级 | 四层齐全且层层递进，每层有具体规范文档，商业层有已验证的变现案例 |
| A 级 | 四层都有但商业层偏薄，变现路径不清晰 |
| B 级 | 只有前两层（有形象有规则），没有人格和商业 |
| C 级 | 只有一张图，没有图谱结构 |

## 实战案例

**案例：AIIP 项目中"老蔡"IP 的四层构建**

| 层级 | 内容 |
|------|------|
| 文化符号 | 潮汕茶文化 + 创业精神 + 务实 + 家族 |
| 审美规则 | 暖色调为主、手绘线条感、6 个标准表情 |
| 角色人格 | 40 岁创业者、务实但不刻板、爱喝茶聊生意、口头禅"先试一下" |
| 商业应用 | 服装（T 恤/帽子）、茶具周边、短视频 IP、品牌代言 |

**层级依赖体现**：老蔡的人格（口头禅"先试一下"、爱喝茶聊生意）直接从第一层文化符号（潮汕茶文化 + 务实创业精神）生长而来；商业应用层的茶具周边、服装也对应着茶文化与创业者形象。四层自下而上咬合，IP 才既有灵魂又能变现——这正是四层图谱"层层依赖"的设计意图。

## 注意事项
- **必须自底向上**：层序颠倒（先画商业蓝图却没想清文化符号）是最常见错误，每一层都要以下层为基础
- **审美规则必须具体**："风格是温暖的"远远不够，要落到色号、比例、表情数量，否则换人就变样
- **人格不能与文化脱节**：角色的口头禅、行为习惯应从文化符号层自然生长出来，否则会"人设崩"
- **AI 时代的关键**：四层图谱本身就是「给 AI 看的 IP 说明书」——规范越具体，AI 批量生成的 IP 内容越一致、越可复用

## 与其他方法的配合
- 前置：创新五大构成（先确定 IP 的五维创造力定位）
- 后续：角色基因理论（第三层角色人格的详细执行框架）、老瓶换新装（第一层文化符号的创新来源）
- 并行：人货场（商业应用层的渠道分析）
