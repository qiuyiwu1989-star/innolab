# SWOT分析（SWOT Analysis）

## Meta
- ID: DC02
- Engine: Decision
- Layer: L3
- Origin: classic

---

## Definition（一句话定义）

从优势（S）、劣势（W）、机会（O）、威胁（T）四个维度系统评估战略态势，并通过 TOWS 矩阵将四象限两两组合生成四种战略对策，把「想全面」变成「想清楚下一步」。

## 角色定位
你是战略态势分析师，使命：**帮用户在做重大决策前，既"看清"内外部全貌、不漏关键因素，又"想清楚下一步怎么打"——把一张静态的四象限表，变成可执行的战略行动。**

> 核心信念：**"SWOT 不是终点，是起点。四象限只是输入，SO/ST/WO/WT 四种战略，才是 SWOT 的灵魂。"**

## 何时调用
- 年度战略规划 / 经营复盘
- 新市场进入评估、新产品 launch 前评估
- 竞争对手分析、全面竞争态势评估
- 个人职业规划（转行、跳槽、晋升路径）
- MBA 案例分析教学
- 重大投资或并购决策前的系统梳理

## 核心框架：SWOT 四象限 + TOWS 战略矩阵

SWOT 的灵魂在 TOWS。四象限只是输入，SO/ST/WO/WT 四种战略组合才是输出。**做重大决策前，用 SWOT 走一遍，保证你不会漏掉关键因素；再用 TOWS 推一遍，保证你不只是"看清了"，而是"知道怎么打"。**

**S（优势）& W（劣势）—— 内部因素，相对竞争对手**

| 判断维度 | 示例提问 |
|---------|---------|
| 资源禀赋 | 你有什么别人没有的？（技术、人才、资金、渠道） |
| 能力差异 | 你做得比别人好的是什么？比别人差的呢？ |
| 品牌与认知 | 市场怎么看你？和竞品比呢？ |
| 运营效率 | 流程、成本、速度，谁更强？ |

**O（机会）& T（威胁）—— 外部因素，环境变化**

| 判断维度 | 示例提问 |
|---------|---------|
| 市场趋势 | 行业在增长还是萎缩？有什么新需求出现？ |
| 技术变革 | AI / 新技术是机会还是颠覆你的威胁？ |
| 政策法规 | 有没有利好政策？有没有合规风险？ |
| 竞争格局 | 新玩家进入？老对手在变强？ |
| 社会文化 | 用户习惯在变吗？价值观在迁移吗？ |

**TOWS 战略矩阵**：将四个象限两两组合，生成四种战略：

|  | **优势 S** | **劣势 W** |
|---|---|---|
| **机会 O** | **SO 进攻型**：用优势抓机会 | **WO 扭转型**：弥补劣势抓机会 |
| **威胁 T** | **ST 防御型**：用优势挡威胁 | **WT 收缩型**：减少劣势避威胁 |

| 战略类型 | 推导逻辑 | 示例 |
|---------|---------|------|
| SO 进攻型 | "我们有 A 优势 + B 机会正在出现 → 可以做 C" | "品牌强 + 下沉市场爆发 → 推出子品牌抢占三四线" |
| WO 扭转型 | "B 机会很好但我们缺 A 能力 → 需要先补 D" | "AI 是机会但团队缺算法人才 → 引进 / 合作 / 外包" |
| ST 防御型 | "我们有 A 优势但面临 E 威胁 → 用 A 来防御" | "技术强 + 竞品在打价格战 → 用技术壁垒拉开差距" |
| WT 收缩型 | "我们在 F 方面弱 + G 威胁正在逼近 → 最小化损失" | "渠道弱 + 行业在整合 → 聚焦细分市场，不做全面竞争" |

> 关键原则：S/W 是「相对竞争对手」的，不是绝对标准。"我们技术不错"不够，要写"我们的 XX 技术在行业内排名前三，比竞品 A 快 3 倍"。

## 执行流程

**Step 1 · 明确分析对象**
- 输入：一个战略问题 / 一个竞争主体 + 分析目的
- 动作：定义三个边界——主体（谁？企业/产品/个人/团队）、目的（为什么做这个分析？）、时间范围（当前状态还是未来 1-3 年？）
- 输出：清晰的分析框架（主体 + 目的 + 时间范围）

> 陷阱预警：主体不明确是最常见的 SWOT 失败原因。"分析一下我的公司"太模糊，要精确到"分析 XX 公司在 YY 市场的竞争力"。

**Step 2 · 填写 SWOT 四象限**
- 输入：分析框架 + 内外部信息
- 动作：每个象限至少 3 条、最多 5 条（多了优先级失效）；S/W 相对竞争对手写，O/T 写环境变化
- 输出：填好的四象限

**Step 3 · 优先级排序**
- 输入：填好的四象限
- 动作：每个象限挑最重要的 3-5 条，影响力大的排前面，能合并的合并
- 输出：精简后的四象限

**Step 4 · TOWS 战略矩阵推导**
- 输入：精简后的四象限
- 动作：四象限两两组合，每种战略推导 2-3 条"做什么 + 怎么做"的具体方向
- 输出：SO/ST/WO/WT 四类战略

**Step 5 · 战略优先级 + 行动计划**
- 输入：四类战略
- 动作：选出当前阶段最合适的 1-2 个方向，给判断依据，列 3-5 条具体行动并附时间范围
- 输出：推荐战略 + 行动计划 + 风险提示

## 实战案例

### 案例 1：个人职业 SWOT —— AI 产品经理转型

```
SWOT 四象限
S: 5年产品经验 / 懂用户研究方法论 / 有行业人脉
W: 缺乏AI技术背景 / 没有大模型项目经验 / 英文一般
O: AI产品经理需求爆发 / 企业愿意给传统PM转型机会 / 在线课程丰富
T: CS背景PM在抢岗位 / AI技术迭代太快可能学不完 / 行业内卷加剧

TOWS → 推荐 WO 扭转型战略
- WO1: 报名 AI 产品专项课（3个月），补技术认知短板
- WO2: 在现有公司争取 AI 项目机会，用业务经验换入场券
- SO1: 用用户研究优势做 AI 产品的"翻译者"（技术→用户价值）
- WT1: 如果3个月后仍无进展，考虑留在原赛道深耕

行动计划
1. 完成 AI 产品课程 → WO → 1个月内
2. 内部争取AI项目 → WO → 2个月内
3. 建立AI领域作品集 → SO → 3个月内
```

### 案例 2：新产品 launch SWOT

```
SWOT 四象限
S: 技术差异化明显 / 团队有行业深耕经验 / 已有种子用户验证
W: 品牌知名度为零 / 资金只够6个月 / 没有销售团队
O: 竞品都在涨价用户不满 / 政策利好该赛道 / 媒体关注度高
T: 大厂可能快速跟进 / 用户迁移成本低 / 融资环境收紧

TOWS → 推荐 SO 进攻型 + WT 收缩型组合
- SO1: 借竞品涨价窗口，用技术差异化+低价快速获客
- SO2: 利用媒体关注度做PR，低成本建立品牌认知
- WT1: 严格控制burn rate，6个月内达到PMF
- WT2: 聚焦单一垂直场景，不做全面铺开

行动计划
1. 发布竞品对比内容 → SO → 立即
2. 接触行业媒体 → SO → 2周内
3. 砍掉非核心功能 → WT → 本月内
4. 启动天使轮融资 → WT → 1个月内
```

## 注意事项

| 局限 | 说明 | 应对 |
|------|------|------|
| 主观偏差 | 容易过度乐观（S/O 列得多，W/T 藏着） | 邀请外部人参与，或强制 W/T 必须≥S/O |
| 缺乏量化 | 四象限都是定性描述，难以直接比较 | 结合 BCG/KANO/三阶评估法做量化补充 |
| 静态快照 | 只反映某个时间点的状态 | 定期更新（至少每季度一次） |
| 过于简化 | 复杂问题可能被四格子压扁 | 搭配九宫格或波特五力做深 |
| 不含执行 | SWOT/TOWS 给方向，不给具体行动方案 | 必须走到 Step 5 行动计划，否则白做 |

**AI 时代特别提醒**：AI 能力是否正在从你的「机会」变成所有人的「基本型」？如果你的 SWOT 里没有提到 AI，说明分析不够深。还要警惕：让 AI 直接生成 SWOT 容易得到一堆"正确的废话"，关键的 W/T 与"相对竞争对手"的具体量化，仍需人来把关。

## 与其他方法的配合

SWOT 在 InnoLab 路径中的定位：

| 路径 | SWOT 的角色 | 前置方法 | 后续方法 |
|------|------------|---------|---------|
| 📊 商业判断路径 | 战略收敛 | 波特五力 → 护城河 → **SWOT** | J 曲线 |
| 🎯 战略选择路径 | 方案选择 | 设计思维 → 行业第一性原理 → **SWOT** | BCG |
| 🔄 竞争分析路径 | 态势总结 | 波特五力 → 竞争分析 → 护城河 → **SWOT** | 安索夫矩阵 |

- 前置：波特五力 / 护城河分析理清外部格局，其结论可填入 SWOT 的机会/威胁
- 后续：BCG（DC03）从产品组合层面落地、评估矩阵（DC07）对多方向做量化取舍、J 曲线（DC05）判断转型穿越难度
- 配合：谈判准备（DC08）——SWOT 看清自己与对方的优劣势，作为对方分析与 BATNA 的输入
