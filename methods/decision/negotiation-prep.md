## 定义

谈判不是"争赢"，是拿到你想要的结果。准备阶段比谈判现场重要 10 倍。

## 五步准备流程

### Step 1：明确目标（三层）

| 层级 | 定义 | 示例 |
|------|------|------|
| **理想结果** | 最好的情况是什么？ | 拿到 100 万投资 |
| **可接受** | 能接受的最低水平 | 50 万 + 资源支持 |
| **底线** | 低于这个就不谈了 | 30 万以下 walk away |

### Step 2：找出 BATNA（最佳替代方案）

**BATNA = 如果这次谈不成，你最好的替代选择是什么？**

- 没有 BATNA 的谈判 = 任人宰割
- BATNA 越强，谈判底气越足
- **在谈判前就准备好 BATNA，而不是谈崩了再想**

### Step 3：分析对方

| 维度 | 你的判断 |
|------|---------|
| 对方的目标是什么？ | |
| 对方的底线可能在哪？ | |
| 对方的 BATNA 是什么？ | |
| 对方的压力在哪？ | |
| 谁是真正的决策者？ | |

### Step 4：设计让步方案

**不要一次性让步，设计让步阶梯：**

| 轮次 | 你让什么 | 换什么 | 节奏 |
|------|---------|--------|------|
| 第一轮 | 价格让 5% | 对方承诺批量 | 试探 |
| 第二轮 | 交付时间延长 1 周 | 对方预付款 50% | 核心交换 |
| 第三轮 | 附加服务 | 长期合同 | 收官 |

**关键原则：** 每次让步都要换东西回来。免费让步 = 信号"我还有空间"。

### Step 5：准备话术

| 场景 | 话术模板 |
|------|---------|
| 开场 | "我们的目标是让双方都拿到想要的结果" |
| 压价 | "这个价格需要我们看哪些方面可以调整？" |
| 拒绝 | "这个我没法直接答应，但我可以做到的是……" |
| 施压 | "我们还有其他选项在同时评估" |
| 收官 | "如果X条件满足，我们今天能确定吗？" |

---

## 使用方法

当用户说"帮我准备谈判"时：

1. **收集信息**：对手是谁、谈什么、你想要什么、底线在哪
2. **走五步准备**：目标→BATNA→对方分析→让步设计→话术
3. **输出谈判准备清单**

**输出格式：**
```
📋 谈判准备清单

🎯 目标：理想[XX] / 可接受[XX] / 底线[XX]
🛡️ BATNA：[如果不谈成，你的最好替代方案]
👤 对方分析：[目标/压力/决策者]
🔄 让步方案：[三轮阶梯]
💬 关键话术：[3-5句]
⚠️ 最大风险：[对方可能的套路]
```
