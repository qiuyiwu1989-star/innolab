# 决定

按时间倒序。每条：定了什么 / 为什么 / 什么时候。
**改主意不是问题，改了却两边记录打架才是问题**——推翻旧决定时，把旧的标「已作废」，别删。

---

## 2026-08-05 · 对外 Skill 采用「厚包 + 回流钩子」

方法卡和案例**随包全量分发**，装上零依赖、离线可用；靠输出末尾的署名和 CTA 引回 innolab.cc 和 1:1。
**为什么**：Skill 的职责是获客不是变现，门槛越低越好。代价是看不到别人怎么用（除非对方主动来）。
被否掉的：薄包（只带索引、方法卡联网拉）——可观测但要联网，装了不能立刻用，漏斗会断。

## 2026-08-05 · 对外版做成「构建产物」，不改私人版

私人 `SKILL.md`（720 行，含记忆库和自进化）原样保留；对外版是 `skill-dist/SKILL.md`（约 200 行），
用 `scripts/build-skill.py` 投影出包。**为什么**：两边手工维护必然漂移（之前已经吃过一次亏——
skill 记 80 个方法、索引只有 74、实际 83）。现在方法数由脚本自动数、自动写。

## 2026-08-05 · 对外包必须脱敏

案例里有真实团队名单（CEO/产品/设计/AI架构/GPU 五个真人），IP 角色名用了真人姓氏。
**决定**：源文件保留真名（自己看着有实感），构建时脱敏成角色；再加一道闸门——
产物里只要还残留敏感词就中止构建、删掉产物、不出包。已做负向测试确认闸门真的会拦。

## 2026-08-05 · 深脑和 InnoLab 的关系：不合并，接协议

深脑是记忆（L2 长期库），InnoLab 是一只感官（战略器官）。深脑自己的说明里就写了
「InnoLab 的战略分析可按同一协议写入」。**上行**（推演→深脑）安全、纯增益，可以先做；
**下行**（深脑→推演）只能开给邱懿武本人和顾问现场模式，**公开用户永远不能碰深脑**（里面有真人档案）。

## 2026-08-05 · 个人中心补齐自助管理

资料可自己编辑（存回留资表）、每条历史可生成分享链接、可改密码。
**为什么**：用账号密码注册的人从没留过资，所以资料永远是空的，页面还没有编辑入口。
**不做**：删账号 / 改邮箱（没有邮箱验证，改邮箱会串号）/ 删单条历史（那是飞轮数据）。

## 2026-08-05 · 可分享的推演报告

每份推演可存成 `/r/<16位随机id>` 公开只读页。
**为什么**：让每份免费推演都变成一个带转化钩子的分发单元——用户觉得有用就转给同处境的朋友。
安全：随机 id 不可枚举、noindex 不进搜索引擎、只有用户主动点分享才落盘。

## 2026-08-04 · 注册不要邮箱验证

只要账号 + 密码。**为什么**：邱懿武明确要求，降低注册摩擦。
**代价与对策**：没有邮箱验证就不能用邮箱认人（会被填别人邮箱串号），
所以 `/me` 的历史按 `auth:<用户id>` 归属，不按邮箱。

## 2026-07 · 产品公开化：从「暗号墙」改成「免费试 + 留资转化」

三档配额：匿名 3 次/天 → 留资 5 次/天 → VIP 不限次；全站 150 次/天兜底。
**为什么**：暗号墙把获客端锁死了，哑铃战略的左半边等于没有。

## 2026-07 · MCP key 保持私发，不建后台

不做自助申请页、不做 key 管理后台，邱懿武手工发。
**为什么**：现在用的人少，建后台是过度建设。等真的发不过来了再说。

## 2026-07 · MCP 走 SSE 流式

**为什么**：一次推演 167 秒，nginx 原来 120 秒就掐断，直接 504。
双管齐下：nginx 超时提到 300 秒 + 每 10 秒发一次心跳保活。

## 2026-07 · 意图澄清用「预设选项」，不用大模型现生成

**为什么**：让模型生成澄清问题要等 18 秒（MiMo 固有延迟），而且它有时返回空数组。
预设选项是瞬时的。只对少于 80 字的提问弹，够详细的直接推。

## 2026-07 · 后台 token 去掉公网兜底值

原来是 `process.env.ADMIN_TOKEN ?? "innolab-admin"`——仓库是公开的，
等于任何人都能读到留资的真实姓名和手机号。**已修**：没配环境变量就直接拒绝，没有兜底值。
